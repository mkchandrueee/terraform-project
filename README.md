#Terraform Multicloud project
In this project we use terraform to automate aws and azure colud resources.

## NIFTY Option Strategy Suite

This repository also hosts a static web app in [`option-strategy-suite/`](option-strategy-suite/) that
implements the NIFTY first-candle option strategy: the Option Analyser, the T1 Decision Helper, the Stoploss
Pullback Entry tool and a Trade Signal stage (market-standard confluence, win estimate, expected profit and
notifications), chained into one workflow. See its
[README](option-strategy-suite/README.md) for the model and its assumptions. `netlify.toml` publishes that
directory.
